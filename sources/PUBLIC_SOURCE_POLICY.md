# Public Source Policy

이 저장소는 Public이므로 다음 원문은 기본적으로 커밋하지 않습니다.

- 미출판 원고 전문
- reviewer/editor decision letter 원문
- response letter 원문
- 계정정보, 이메일, 전화번호 등 개인정보가 포함된 submission 자료
- 분석 로그, raw coding data, 유료 DB에서 취득한 원문

## 왜 원문을 바로 올리지 않는가
1. 미출판 원고의 공개가 향후 투고·preprint 정책과 충돌할 수 있음
2. reviewer/editor correspondence는 비공개 심사 커뮤니케이션일 수 있음
3. submission export에는 계정정보·개인정보가 섞일 수 있음
4. 공개 저장소는 검색엔진과 크롤러에 노출됨

## 대신 무엇을 보존하는가
- public-safe case summary
- 저자 원고에서 일반화 가능한 짧은 anti-pattern 예시
- reviewer/editor 지적의 요지와 대응 원칙
- private source filename/ID를 직접 노출하지 않는 source-class 설명

## 실제 검수에서 원문이 필요할 때
사용자가 현재 대화/Project에 제공한 private manuscript와 decision letter를 직접 읽어
public rule과 대조합니다. Git case file은 독립 근거가 아니라 재사용 가능한 검수 프레임입니다.
