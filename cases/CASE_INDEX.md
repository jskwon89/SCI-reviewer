# Case Index

이 폴더는 실제 심사 실패에서 일반화된 검수 사례를 보존합니다.

## 2026-A — Court-record stalking manuscript
파일: `2026_A_COURT_RECORD_STALKING_PUBLIC_CASE.md`

주요 실패 축:
- 내부 분석언어가 publication prose로 유출
- 방어적 caveat 누적
- method novelty가 substantive contribution보다 앞섬
- 외부 독자의 Methods/Results 해독 부담
- 이전 revision/QA 맥락을 아는 저자에게만 자연스러운 표현

## 2026-B — Fear-of-crime / social cohesion multilevel manuscript
파일: `2026_B_FEAR_COHESION_MULTILEVEL_PUBLIC_CASE.md`

주요 실패 축:
- theory–RQ–analysis hierarchy 불일치
- primary와 secondary/exploratory의 수사적 위계 불일치
- 여러 이론축이 중심 기여와 경쟁
- 개별 문장은 합리적이나 argument progression이 fragmented
- revision 후 중심 분석이 바뀌었지만 옛 hypothesis architecture가 남음

## 사용법
새 원고 검수 시 사례와 구조적으로 유사한 위험이 있는지 확인합니다.
사례 파일은 원문 전체를 대체하지 않습니다. 정밀 검수에서는 사용자가 제공한 private manuscript/decision source를 직접 대조합니다.
