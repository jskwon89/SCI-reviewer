# AI-Like Style / Author-Voice Audit

이 체크리스트는 AI authorship를 판정하지 않는다.
문체의 기계적·정형적 위험을 점검한다.

## Repetition
- [ ] 동일 sentence opener가 한 section에서 3회 이상 반복되지 않는다.
- [ ] 3–6 word 비전문 phrase가 반복적으로 재사용되지 않는다.
- [ ] Abstract / Introduction / Discussion / Conclusion이 같은 문장을 거의 그대로 반복하지 않는다.
- [ ] 동일한 conclusion phrase가 여러 subsection 끝에 반복되지 않는다.

## Rhetorical templates
- [ ] This study / These findings / Taken together / Importantly / Notably의 반복을 점검했다.
- [ ] Although X, Y / While X, Y / Rather / This suggests that 구조가 연속적으로 반복되지 않는다.
- [ ] 모든 paragraph가 claim → caveat → implication의 동일 틀을 갖지 않는다.

## Concreteness
- [ ] 추상 주어보다 실제 연구대상·자료·결과가 주어로 나온다.
- [ ] nominalization이 동사보다 과도하게 많지 않다.
- [ ] generic importance language 대신 무엇이 왜 중요한지 구체적으로 썼다.

## Defensive style
- [ ] may/might/could/potentially/possibly가 한 문단에 누적되지 않는다.
- [ ] does not imply / should not be interpreted가 반복되지 않는다.
- [ ] reviewer 대응 흔적이 본문에 남아 있지 않다.

## Rhythm
- [ ] 문장 길이가 지나치게 균일하지 않다.
- [ ] 모든 paragraph가 같은 길이와 같은 문장 수를 갖지 않는다.
- [ ] 병렬 3항 구조를 습관적으로 반복하지 않는다.

## Author voice
- [ ] 가능하면 저자의 기존 출판 논문 1–3편과 비교했다.
- [ ] 평소보다 지나치게 추상적·장황·방어적이지 않다.
- [ ] 저자가 평소 쓰지 않는 공식적 transition phrase가 대량으로 등장하지 않는다.

## Publication-prose contamination
- [ ] 연구 자체가 아니라 수정·검증·방어 과정을 설명하는 meta prose가 남아 있지 않다.
- [ ] "during revision", "to address this concern", "retained specification" 같은 표현을 문맥상 점검했다.
- [ ] 추상 주어가 실제 변수·집단·결과를 숨기지 않는다.
- [ ] 단어 빈도만으로 DEFENSIVE / ABSTRACT / TEMPLATE 문제를 판정하지 않았다.
- [ ] 문제가 있다면 실제 문장 또는 위치와 구체적 수정안을 제시했다.
- [ ] final/revised/current/baseline 등은 blacklist가 아니라 문맥상 revision trace인지로 판정했다.

## Field norm
- [ ] 목표 저널 recent papers와 문장 밀도·transition·Discussion voice가 크게 어긋나지 않는다.

## 수정 후 확인
- [ ] AI-like 표현을 줄인다고 문법을 일부러 깨뜨리지 않았다.
- [ ] detector 회피 목적의 임의 paraphrase를 하지 않았다.
- [ ] 의미·수치·인용·분석범위가 바뀌지 않았다.
