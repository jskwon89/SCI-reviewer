# Author Drafting Checklist

## Before writing
- [ ] 중심 contribution을 한 문장으로 정했다.
- [ ] primary RQ/H와 main analysis를 정했다.
- [ ] secondary/exploratory boundary를 정했다.
- [ ] 목표 저널 recent peer papers를 확인했다.
- [ ] section별 기능과 대략적 word budget을 정했다.
- [ ] author-voice baseline이 있으면 확보했다.

## During Introduction
- [ ] problem → known evidence → gap → importance → present study가 이어진다.
- [ ] literature 나열이 아니라 논리 연결을 썼다.
- [ ] primary와 무관한 이론을 추가하지 않았다.
- [ ] 뒤에서 설명할 용어를 먼저 쓰지 않았다.

## During Method
- [ ] 외부 독자가 sample flow를 이해할 수 있다.
- [ ] 내부 QA/revision 용어를 사용하지 않았다.
- [ ] 복잡한 규칙에는 예시가 있다.
- [ ] caveat를 필요한 위치에서만 썼다.

## During Results
- [ ] 표 수치를 전부 반복하지 않았다.
- [ ] 핵심 패턴을 평문으로 설명했다.
- [ ] primary 결과가 가장 눈에 띈다.

## During Discussion
- [ ] closest literature와 직접 비교했다.
- [ ] 가능한 설명과 alternative explanation을 구분했다.
- [ ] 자료가 허용하지 않는 해석을 넘지 않았다.
- [ ] theory/measurement/practice implication 중 실제 필요한 것을 충분히 설명했다.

## Style
- [ ] sentence opener 반복을 점검했다.
- [ ] generic transition과 importance language를 줄였다.
- [ ] nominalization과 추상 주어를 줄였다.
- [ ] 모든 문단이 같은 구조로 반복되지 않는다.
- [ ] 저자의 기존 published voice와 크게 벗어나지 않는다.

## Completion
- [ ] field norm과 section depth가 적절하다.
- [ ] publication-context independence를 통과한다.
- [ ] 더 복잡하게 만드는 것보다 더 명확하게 만드는 것을 우선했다.
