# Pre-Submission Reader Clarity Checklist

하나라도 FAIL이면 submission-ready로 판정하지 않는다.

## Core contribution
- [ ] 기여를 통계기법 이름 없이 한 문장으로 설명할 수 있다.
- [ ] gap이 아무도 이 분석을 안 했다는 수준을 넘어선다.
- [ ] 왜 중요한지 이론/측정/실무 중 하나 이상에서 명시된다.

## Section alignment
- [ ] Title, Abstract, Introduction, RQ/H, main model, Results, Discussion이 같은 중심을 갖는다.
- [ ] primary analysis가 main tables/figures의 대부분을 차지한다.
- [ ] Supplement 분석이 formal hypothesis를 독점하지 않는다.

## Argument
- [ ] Introduction 각 문단의 기능을 한 단어로 붙일 수 있다.
- [ ] 문단 간 연결이 명시적이다.
- [ ] 뒤에서 정의되는 개념을 앞에서 사용하지 않는다.
- [ ] 필요한 이론만 남겼다.

## Terminology
- [ ] 자체 제작 용어가 꼭 필요한 것만 남아 있다.
- [ ] 평문 설명 후 라벨이 나온다.
- [ ] 한 문장에 새 전문개념이 2개 이상 나오지 않는다.
- [ ] 지시어의 선행사가 즉시 명확하다.
- [ ] 국내 시스템이 국제 독자에게 설명돼 있다.

## Methods
- [ ] 데이터에 익숙하지 않은 연구자가 표본구성을 설명할 수 있다.
- [ ] 복잡한 규칙에는 실제 예시가 있다.
- [ ] 시작 N → 제외/포함 → 최종 N을 쉽게 추적할 수 있다.

## Results
- [ ] 기술 라벨을 그대로 반복하지 않고 평문으로 해석한다.
- [ ] Method로 계속 돌아가지 않아도 Results를 읽을 수 있다.
- [ ] secondary/exploratory 결과가 primary보다 길지 않다.

## Discussion
- [ ] 첫 문단이 무엇을 새롭게 알게 되었는가를 설명한다.
- [ ] 추상문장 뒤에 실제 대상과 조건이 나온다.
- [ ] 방법론 내부 용어가 implication 문단까지 남지 않는다.
- [ ] 자료가 지지하지 않는 behavioral/causal 의미를 붙이지 않는다.

## Defensive-writing / revision-trace
- [ ] 핵심 주장보다 caveat가 더 길지 않다.
- [ ] 동일 방어적 제한을 여러 섹션에서 반복하지 않는다.
- [ ] 현재 본문을 이해하는 데 이전 버전이나 reviewer response가 필요하지 않다.
- [ ] final/revised/clarified/retained/baseline/corrected가 내부 수정 이력을 암시하지 않는다.
- [ ] 범주는 exclusion chain보다 positive definition으로 먼저 설명한다.
- [ ] 명사 더미와 하이픈 연쇄 때문에 독자가 문장을 해독해야 하지 않는다.
- [ ] 추상 주어의 실제 대상이 명확하다.
- [ ] 비전문 동료가 Methods 핵심 절차를 원고만 읽고 설명할 수 있다.

## Field norm
- [ ] 최소 5편의 동종 peer paper와 비교했다.
- [ ] 분석 수·용어 수·Methods 깊이·Supplement 규모가 목표 저널 관행과 크게 어긋나지 않는다.


## Section depth / word budget
- [ ] 전체 분량이 peer set보다 짧다면, 그 이유가 중복 제거이지 conceptual omission이 아닌지 확인했다.
- [ ] Introduction이 problem → known evidence → gap → importance → present study를 충분히 연결한다.
- [ ] Results가 table callout 수준으로 끝나지 않고 핵심 패턴을 평문으로 해석한다.
- [ ] Discussion이 closest literature 비교, alternative explanation, boundary condition, implication을 필요한 만큼 다룬다.
- [ ] 별도 Conclusion이 있다면 2–4문장 결과 반복으로 끝나지 않고 contribution을 독립적으로 압축한다.
- [ ] 분량을 늘리기 위해 새 분석·새 이론·새 robustness를 추가하지 않았다.
