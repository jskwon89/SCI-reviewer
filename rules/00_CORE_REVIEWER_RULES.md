# 00. Core Reviewer Rules

## A. 한 논문에는 하나의 중심 주장만 둔다
중심 기여는 통계기법 이름이 아니라 무엇을 새롭게 알게 되었는가를 말해야 한다.

## B. 모든 섹션은 같은 중심을 말해야 한다
Title, Abstract, Introduction gap, RQ/H, Primary analysis, Main Results, Discussion/Conclusion이 같은 중심을 가리켜야 한다.

## C. 독자가 알아야 할 순서대로 쓴다
문제 → 왜 중요한가 → 기존 연구가 무엇을 놓치는가 → 이번 연구가 무엇을 묻는가 → 최소 용어 → 방법 → 결과 → 의미와 한계.

## D. 정확성과 이해 가능성을 동시에 충족한다
정확하지만 독자가 이해하지 못하면 실패다. 쉬우나 자료가 지지하지 않으면 역시 실패다.

## E. structure 지적 시 patch revision을 중단한다
unclear contribution, fragmented argument, difficult to follow, hard to interpret/replicate, jargon, substantial restructuring, theory–RQ–analysis misalignment가 나오면 line-edit가 아니라 architecture 문제로 분류한다.

## F. Field-normality를 별도 합격 기준으로 둔다
분석·문장·용어·표·Supplement의 밀도가 동종 사회과학 논문과 현저히 다르면 그 차이가 학문적 필요 때문인지 내부 검증 습관 때문인지 확인한다. 더 자세함 = 더 좋음으로 간주하지 않는다.
