# 03. Methods Clarity and Replicability

## 1. Methods는 규칙 목록이 아니라 재현 가능한 이야기로 쓴다
원자료 → 관측단위 → 포함/제외 → 중복처리 → 최종 표본 → 변수/분류 → primary 분석 순서.

## 2. 복잡한 표본구성에는 최소 1개의 실제 예시를 둔다
입력 상태, 적용 규칙, 최종 관측치 수를 보여준다.

## 3. 용어 정의만으로 재현성이 충족되지 않는다
독자가 실제 자료 한 건을 보고 같은 결정을 내릴 수 있어야 한다.

## 4. 숫자 flow와 개념 flow를 분리한다
시작 N → 주요 inclusion/exclusion → 최종 N은 쉽게 추적 가능해야 한다.

## 5. software/data conventions를 숨은 전제로 두지 않는다
데이터셋이나 제도에 익숙하지 않은 독자가 이해할 수 있어야 한다.

## 6. Results에서 쓸 라벨을 Methods에서 자연어로 먼저 설명한다

## 7. 한계는 Methods와 Discussion에서 일관되게 유지한다
proxy, cross-sectional, documented anchor 등 한 번 붙인 제한을 뒤에서 잊지 않는다.
