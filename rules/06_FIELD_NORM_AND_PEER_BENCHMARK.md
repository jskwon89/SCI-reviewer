# 06. Field-Norm and Peer-Benchmark Audit

## 목적
원고가 분석적으로 정확하고 논리적으로 이해 가능하더라도, 같은 분야의 일반적인 사회과학 논문과 비교해 지나치게 복잡하거나 자체 용어가 많거나 분석·검증의 깊이가 비정상적으로 크면 독자와 reviewer가 이질적으로 느낄 수 있다.

## 1. 비교 논문 선정
최소 5편, 권장 8–12편의 최근 peer-reviewed 논문과 비교한다.
우선순위:
1. 목표 저널 최근 3–5년 논문
2. 동일 자료유형/방법론 논문
3. 동일 주제의 인접 저널 논문
4. 저자의 대표 논문 중 해당 저널 문체에 잘 맞는 논문

## 2. 비교 축
- 분석 복잡도: main/secondary/sensitivity 모델 수, 표·그림, Supplement
- 용어 밀도: 자체 용어, acronym, hyphenated compound, 암기해야 할 분류체계
- 문장 기술 방식: 문장 길이, clause, nominalization, 추상 주어, caveat, 통계 밀도
- Methods 깊이: 데이터, 표본 flow, 변수, 코딩, reliability, sensitivity, software, missing data
- Results 밀도: abstract 숫자 수, 표 수치 반복, effect size/CI/p의 밀도
- Theory/contribution: 이론 수, hypothesis 수, descriptive study의 claim 수준

## 3. Field-normality FAIL 신호
다음 중 2개 이상이면 구조 재검토:
- too technical / dense / jargon / difficult to interpret 지적
- 유사 논문보다 자체 용어가 현저히 많음
- Supplement가 main text와 비슷하거나 더 큼
- secondary/sensitivity 분석 수가 primary보다 많음
- abstract에 여러 분석 결과가 병렬적으로 과다 제시됨
- Introduction에 독립 이론축이 3개 이상 경쟁
- Results를 읽기 위해 Method 정의를 반복 검색
- 동일 caveat가 여러 절에 반복
- 일반 논문에서 table note 수준인 내용을 본문에서 장문 설명

## 4. Peer-style calibration의 목적
문장을 복사하는 것이 아니라 정보 밀도, 용어 수, 설명 깊이, 결과 선택성, 이론 범위, 표·보충자료 규모, 문장 구체성을 맞춘다.

## 5. Target-journal override
general social science norm → subfield norm → target journal norm 순으로 좁혀가며, 최종 판단은 목표 저널 최근 관행을 우선한다.
