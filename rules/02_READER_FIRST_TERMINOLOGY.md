# 02. Reader-First Terminology

## 1. 내부 분석언어를 독자 언어로 자동 승격하지 않는다
특히 factual unit, analytic relationship, documentary relationship, same-dyad, fixed denominator, pair-bearing case, eligibility rule, construction sequence를 경계한다.

필요하면 실제 의미를 평문으로 먼저 설명한다.
- same-dyad conduct → conduct involving the same defendant and the same victim
- factual unit → one underlying act or event described in the record

## 2. 자체 제작 용어는 최소화한다
반복이 꼭 필요하고, 기존 용어로 대체 불가하며, 한 문장으로 설명 가능한 경우만 유지한다.

## 3. 한 문장에 새 개념을 2개 이상 도입하지 않는다

## 4. 지시어 선행사를 명시한다
the record, these relationships, this pattern, this category, these findings의 선행사가 애매하면 구체명사를 반복한다.

## 5. 지나친 압축을 피한다
짧은 문장이 의미를 숨기면 2~3문장으로 풀어 쓴다.

## 6. 국제 독자에게 자명하지 않은 국내 시스템을 설명한다
DB, 법적 조치, 표본추출 단위, 행정구역 등을 처음 등장할 때 짧게 설명한다.

## 7. 자료 라벨을 행동적 실체처럼 쓰지 않는다
- separate charge ≠ separate behavior
- area mean ≠ objective neighborhood property
- documented first act ≠ true onset
- indirect association ≠ causal mediation

## 8. 명사 더미와 하이픈 연쇄를 경계한다
judgment-documented stalking course, stalking-course-offense pair, same-act deduplication처럼 명사를 연속 결합하면 독자의 해독 비용이 커진다.

## 9. 추상 명사를 행위 주체처럼 쓰지 않는다
The record shows, These findings shift interpretation, The framework indicates처럼 무엇이 무엇을 하는지 불명확한 추상 주어를 경계한다.

## 10. 정의는 긍정형으로 먼저 쓴다
실제 무엇을 포함하는지 → 대표 예시 → 필요한 경우 exclusion rule 순으로 쓴다.

## 11. 저자만 아는 시간축을 독자에게 강요하지 않는다
final, revised, clarified, retained, baseline, original, previous, corrected, locked, harmonized가 이전 버전/내부 QA를 암시하는지 점검한다.
